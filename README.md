# Redeas_do_Bem
# 🐴 Rédeas do Bem

## 📌 Sobre o Projeto

O **Rédeas do Bem** é um projeto voltado à **conscientização e divulgação de informações sobre a adoção de equinos resgatados**, com foco na cidade de **Aracaju, Sergipe**.

A proposta é reunir informações sobre o processo de adoção, os requisitos necessários e os serviços públicos relacionados ao acolhimento e cuidado desses animais, contribuindo para a conscientização sobre a causa animal e a adoção responsável.

O projeto foi desenvolvido como uma **iniciativa de estudo e prática**, utilizando ferramentas de desenvolvimento web para transformar informações de interesse público em uma experiência digital acessível.

---

## 🎯 Objetivo do Projeto

O objetivo do Redes do Bem é facilitar o acesso a informações sobre a adoção responsável de equinos resgatados, incentivando a conscientização e o cuidado com esses animais.

A proposta busca:

- Divulgar informações sobre a adoção de equinos resgatados;
- Apresentar orientações e requisitos relacionados ao processo de adoção;
- Reunir informações sobre os serviços públicos envolvidos;
- Incentivar a responsabilidade e o bem-estar animal;
- Tornar informações de interesse público mais acessíveis por meio de uma interface web.

As informações utilizadas como referência foram pesquisadas em fontes oficiais da Prefeitura de Aracaju.

## 👩‍💻 Autoria e Desenvolvimento

Projeto desenvolvido por **Laissa Nunes**, como parte de sua jornada de aprendizado e prática em desenvolvimento web.

A estrutura inicial da interface foi criada com o auxílio da plataforma **Lovable** ([lovable.dev](https://lovable.dev)), utilizada como ferramenta de apoio à construção do layout e da estrutura inicial do projeto.

O projeto tem finalidade educacional e de prática, permitindo explorar tecnologias de desenvolvimento web e aplicar conhecimentos adquiridos durante os estudos.

**Observação:** o projeto não representa um serviço oficial da Prefeitura de Aracaju e não realiza diretamente o processo de adoção. As informações apresentadas têm caráter informativo.

## 🛠️ Tecnologias Utilizadas

O projeto utiliza as seguintes tecnologias e ferramentas:

- **React** — construção da interface e dos componentes;
- **TypeScript** — tipagem estática e organização do código;
- **Vite** — ambiente de desenvolvimento e ferramenta de build;
- **Tailwind CSS** — estilização da interface;
- **shadcn/ui e Radix UI** — componentes e recursos para a interface;
- **Lucide React** — ícones;
- **React Router DOM** — navegação entre páginas;
- **Node.js e npm** — ambiente e gerenciamento de dependências para executar o projeto.

## 🚀 Como Executar o Projeto

### Pré-requisitos

Antes de começar, você precisa ter instalado:

- [Node.js](https://nodejs.org/)
- npm, incluído na instalação do Node.js

### Instalação

1. Clone este repositório:

   ```bash
   git clone https://github.com/laissa-nls/Redeas_do_Bem.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Redeas_do_Bem
   ```

3. Acesse a pasta que contém o código da aplicação, se necessário:

   ```bash
   cd redeas-do-bem-codigo
   ```

4. Instale as dependências:

   ```bash
   npm install
   ```

5. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

6. Abra no navegador o endereço local exibido no terminal.
